- [**CEBRA**](https://github.com/AdaptiveMotorControlLab/CEBRA) (1000+ stars): Core contributor. Developing model architectures, inference/data pipelines, and reproducible API for a widely-used open-source representation learning framework for biological time-series analysis.
- [**FreelyMovingVR4Mice**](https://github.com/MMathisLab/FreelyMovingVR4Mice) (related to [Benquet et al. 2026](#publications)): Core contributor. Developing an open-source software framework integrating Unity, behavioral control, and hardware interfaces for freely moving virtual reality experiments in mice.
- [**CEBRA-lens**](https://github.com/AdaptiveMotorControlLab/CEBRA-lens) (under active development): Core contributor. Developing a Python library for mechanistic interpretability of CEBRA models.
